# Third-party notices

This directory contains the direct license texts for the pinned media/runtime
components. The Windows libmpv artifact is an aggregate build; public binary
distribution must additionally ship or offer the complete corresponding source
and notices for its exact transitive build as described in `DEPENDENCIES.md`.
The WebView2 SDK loader license and its upstream third-party notice are included
as separate files.
Qt 6 is dynamically linked under LGPL-3.0-only; its license text is included as
`Qt-LGPL-3.0-only.txt`, and the portable package keeps the Qt DLLs replaceable.
